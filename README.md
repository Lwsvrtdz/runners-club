# 7PM Runners Club

Interactive website for **7PM Runners Club** — night runs in Maples Grove, General Trias, Cavite.

## Weekly rhythm

- **Monday 7:00 PM** — Easy runs
- **Friday 7:00 PM** — Speed sessions
- **Weekends** — LSD (Long Slow Distance)

## Stack

- Nuxt 4 + Vue 3 + TypeScript
- Tailwind CSS
- VueUse

## Develop

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000).

## Build

```bash
npm run build
npm run preview
```

## Notes

Event registration and membership forms are front-end demos only — no backend persistence.
Logo asset: `public/logo.png`.
